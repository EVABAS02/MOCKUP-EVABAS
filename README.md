# 🚀 Mockup Studio Pro - EVABAS

**Outil de génération de mockups d'écrans pour designers et développeurs**

---

## 📌 À propos du projet

**Mockup Studio Pro** est un outil **100% statique** (HTML/CSS/JS) conçu pour créer des **rendus réalistes de sites web et applications** sur différents types d'écrans.

---

## ✨ Fonctionnalités

| Fonctionnalité | Description |
|----------------|-------------|
| 📁 **Upload d'images** | Glisser-déposer ou sélection manuelle de captures |
| 🎨 **4 Modes de rendu** | Device Simple, Page Longue, Présentation Pro, Trio Responsive |
| 📱 **Formats d'écran** | Desktop (1440×900) et Mobile (390×844) |
| 🎨 **25+ Palettes de couleurs** | Ambiance personnalisable |
| 🖼️ **Effet Glassmorphism** | Rendu moderne et élégant |
| 💾 **Export PNG** | Téléchargement direct du rendu |
| 🎯 **Personnalisation** | Textes, signature et badge |

---

## 📥 Installation & Lancement

### Prérequis
- **Aucune dépendance** nécessaire (projet 100% statique)
- Navigateur moderne (Chrome, Firefox, Edge)

### Méthode recommandée
```bash
cd /chemin/vers/mockup
php -S localhost:8000
```
→ Ouvrez [http://localhost:8000](http://localhost:8000)

---

## 🎯 Utilisation

1. **Chargez une image** (glisser-déposer ou clic)
2. **Sélectionnez un mode** (Device Simple, Page Longue, Présentation Pro, Trio)
3. **Personnalisez** (nom, badge, titre, couleurs)
4. **Exportez** en PNG
